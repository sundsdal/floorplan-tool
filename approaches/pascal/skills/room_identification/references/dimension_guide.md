# Standard Object Dimensions (Reference Guide)

Use these standard sizes to estimate room dimensions from video. When a reference object is visible, use it as an anchor and derive surrounding measurements proportionally.

| Object | Width | Height | Notes |
|--------|-------|--------|-------|
| Interior door | 0.8 - 0.9m | 2.0 - 2.1m | Most common residential door |
| Exterior door | 0.9 - 1.0m | 2.0 - 2.1m | Slightly wider than interior |
| Double door | 1.4 - 1.8m | 2.0 - 2.1m | Two panels |
| Sliding glass door | 1.5 - 2.4m | 2.0 - 2.1m | Patio/balcony access |
